Notes

Generalising effort. Making code reusable by several apps takes about 30 % more work than writing it for one. (COCOMO II, RUSE)
Drift. Each year, copies diverge by ~20 %, so every later change costs more to apply everywhere.
Bug duplication. A bug in copied code is usually fixed twice — or not everywhere.
